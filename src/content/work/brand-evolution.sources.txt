Screenshot sources — staffbase.com brand evolution
====================================================

Reference list for the screenshots used in brand-evolution.mdx.
Maps each image file to the page it was captured from, with exact
Wayback Machine timestamps, so a date in a caption is always
traceable back to a real snapshot.

Note on dates: most captions use the Wayback snapshot date directly.
Two images are an exception — the December 2018 relaunch (see below) —
where the caption shows the actual relaunch date rather than the date
of the earliest available archive snapshot, because those aren't the
same thing and the gap between them is documented here, not silently
collapsed.

Gaps / things worth double-checking
--------------------------------------
- staffbase-2018-12-en.png and staffbase-2018-12-de.png are dated
  "December 2018" in the case study, but the underlying Wayback
  snapshots are from January and April 2019 respectively — the
  earliest archive coverage available, not the relaunch date itself.
  This is a deliberate choice, not an error: the relaunch happened in
  December 2018 per the actual project record, Wayback just didn't
  crawl it until later. Flagging here so the gap is documented rather
  than invisible.
- staffbase-2021-03-bananatag.png was originally mislabeled "April
  2021" before being checked against this list; the Wayback date and
  the public merger-announcement date both independently point to
  March 4, 2021, so this one was a genuine correction rather than an
  intended-vs-archived gap like the December 2018 pair.
