Screenshot sources — VOICES conference website
================================================

Reference list for the screenshots used in voices-conference-website.mdx.
Maps each image file to the page it was captured from, with capture dates
so future drift on the live pages (countdown numbers, next-event
announcements, etc.) doesn't get mistaken for a documentation error.

Gaps / things worth double-checking
--------------------------------------
- All live (non-Wayback) captures were taken June 22, 2026. Since these
  are production pages, anything dependent on "days until the event" or
  "next event announcement" will drift from what's shown here over time —
  the screenshots are a snapshot of that specific afternoon, not a
  permanent state of those URLs.
